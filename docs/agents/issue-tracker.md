# Issue tracker: GitHub

Use existing GitHub Issues in the owning repository; infer it from that repo's
origin. Workspace coordination lives in `viptv-org/workspace`. Read the ticket
and comments before implementation; publish decisions and remaining acceptance
there rather than making a second local issue tracker.

Use `gh issue view`, `gh issue list`, `gh issue create`, `gh issue comment` and
`gh issue edit` in that checkout. PRs as a request surface: no.
